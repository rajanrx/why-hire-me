# Design

## Rights boundary

PolyForm Strict is the public copyright and patent licence. `COMMERCIAL-LICENSING.md` explains how to
request rights that the public licence does not grant, without pretending to grant those rights by
itself. The trademark policy remains a separate identity boundary.

## Discovery boundary

Governed outputs carry `why-hire-me.build/v1`, a non-personal static marker. A maintainer may search
public GitHub code for that marker. Generated pages make no network request, so private portfolios
are not disclosed and public discovery depends on indexing and marker retention.
